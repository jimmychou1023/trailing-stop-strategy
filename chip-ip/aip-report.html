研究結論

回落到 $23.89 · 報酬風險轉佳 · 小額分批

晶片內互連(NoC)IP 領導者,授權+權利金模式、ACV+權利金 +44%、FY26 指引正自由現金流並目標 Q4 轉盈。Q2 營業虧損擴大 + 近日半導體殺盤,股價自 $50 高點續跌到 $23.89(8/21)。基本面沒變、股價卻跌向 Bear 區,機率加權合理價約 $31(預期差 +30%),報酬風險比約 2.68:1。成長題材佳、回檔後安全邊際改善,但仍屬未全面獲利的小型高 beta 股——建議小·試探部位、分批,盯 Q4 轉盈進度。

1一頁研究表 · 12 問
Business1 · 公司靠什麼賺錢?
賣什麼、誰付錢、客戶為什麼換不掉它。
Arteris 賣的是半導體系統 IP,核心是晶片內互連(Network-on-Chip, NoC)——讓一顆 SoC 裡數十上百個電路區塊高效溝通的「神經網路」(產品線如 FlexNoC、Ncore)。
商業模式:授權金(licensing)+ 出貨後權利金(royalties)。付錢的是晶片設計公司、車廠、AI 晶片與資料中心 SoC 廠。換不掉的原因:一旦 NoC 被設計進晶片,重做風險高、且該晶片每出貨一顆都付權利金——黏著度高、收入具經常性。
TAM2 · 市場還能成長多久?
TAM 是判斷成長空間,不是簡報用的。
晶片越複雜,互連越重要。AI 加速器、chiplet(小晶片)、車用 SoC 的區塊數與資料流暴增,直接拉高 NoC 需求。ACV+權利金 +44% YoY 反映需求強勁。
這是「賣鏟子」的位置——不押單一晶片成敗,而是隨整體半導體設計活動成長。TAM 隨設計複雜度長期擴大,關鍵在能否持續拿到新設計 win。
Moat3 · 為什麼對手搶不走?
好到別人無法取代,才叫護城河。
護城河:商用 NoC IP 的領導地位(相對客戶自研,省時間與風險)、設計 win 的多年權利金黏著、架構中立(不綁單一 CPU 指令集,可搭 Arm / RISC-V / x86)。
誠實面:對手是 Synopsys(SNPS)、Cadence(CDNS)、Arm 等 IP / EDA 巨頭,資源遠大;大型客戶也可能自研 NoC。護城河是「專精 + 黏著 + 中立」,但非壟斷,需靠持續技術領先與新 win 維持。
Revenue4 · 成長來自哪裡?
價格還是數量?一次性還是 recurring?
Q2 2026 營收 $24.1M(創高、優於指引)、Q1 $22.9M(+39%)。更關鍵的領先指標是 ACV+權利金 $99.5M(+44% YoY)——代表未來可實現的合約與權利金水位。
成長來自新授權合約(客戶開新專案)＋既有客戶晶片放量的權利金。屬性:授權 + recurring 權利金,能見度佳。FY26 營收指引 $91–95M。
Margin5 · 利潤率是否改善?
Gross → Operating → FCF 一路看營業槓桿。
IP 授權模式毛利率天生很高(軟體式、幾無邊際成本)。問題在營業層面仍小幅虧損:FY26 non-GAAP 營業損益指引 -$4.5~8.5M,且 Q2 營業虧損比市場預期大(股價因此回落)。
好消息:管理層目標最快 Q4 2026 達 non-GAAP 營業轉正。看點是營收放大能否兌現營業槓桿、把虧損收斂到轉盈。
FCF6 · 現金有沒有真的進來?
EPS 是會計結果,現金流較難長期演戲。
難得的優點:即使帳面小虧,FY26 指引為正自由現金流——因為授權/權利金常有預收與遞延,現金進帳早於損益認列。
要留意:股權薪酬(SBC)造成 GAAP 與 non-GAAP 差距與稀釋,看的時候兩套並看。整體現金體質對小型股相對健康,不需靠大額增資。
Balance Sheet7 · 能撐過景氣下行嗎?
小型股尤其要看資產負債表。
手上有現金、無重大有息負債,加上正自由現金流,短期營運無虞、不必靠增資延命(與 AEVA 那種燒錢股不同)。
但要誠實:規模小(營收 ~$95M / 市值 ~$1.4B),抗景氣循環與風險偏好逆轉的能力有限。撐得過一般下行,但屬高 beta 小型股。
Competition8 · 最大競爭者是誰?
用對手財報交叉驗證你這家的說法。
主要對手:Synopsys(SNPS)、Cadence(CDNS)、Arm —— 都提供互連 / IP 且規模龐大;以及大型客戶的自研 NoC。
Arteris 的差異化在專精 NoC + 架構中立 + 純 IP 供應商定位。交叉驗證:看 SNPS / CDNS / ARM 的 IP 業務動能,以及 AI 晶片 / 車用 SoC 客戶的設計活動,能判斷 Arteris 的 win 是否持續。
Catalyst9 · 未來 12–24 個月的催化劑?
把催化劑與時點寫下來。
  • Q4 2026 non-GAAP 營業轉盈的達成——最關鍵的再定價事件。
  • ACV+權利金維持 +40% 級成長,並轉為營收。
  • AI / chiplet SoC 設計爆發帶動新授權 win。
  • 車用 / 資料中心大客戶的新 design win。
  • 約 11 月 Q3 2026 財報。
Expectations10 · 股價已經反映什麼?
Expectations Gap 預期差才是重點。
市值 ~$1.1B ÷ 營收 ~$95M ≈ 約 11–12 倍 P/S。市場已反映高成長與 Q4 轉盈預期;但 Q2 營業虧損擴大 + 半導體殺盤,股價自 $50 高點跌到 ~$23.6,已大幅消化樂觀。
52 週 $8.42→$50.26 顯示這是情緒與流動性驅動極強的小型股。預期差轉正(+30%)——成長是真的、回檔後估值便宜,但獲利兌現與小型股風險並存,宜以試探部位參與。
Valuation11 · Bear / Base / Bull 各值多少?
三情境比單一目標價有意義,詳見下方第 2 區。
AIP 屬尚未全面獲利的小型成長股,用 P/S 與「轉盈時點」評估較合理。核心變數:ACV/權利金成長、Q4 轉盈達成度、半導體設計週期、風險偏好。三情境見下一區(依 8/21 約 $23.9 校準),不確定性高。
Thesis Break12 · 什麼事代表我錯了?
進場前就寫好,跌 40% 後大腦會自動編故事。
先寫下「認錯訊號」:
  • ACV+權利金成長明顯放緩(掉到 +20% 以下)。
  • Q4 未如期轉盈、營業虧損持續擴大。
  • 流失重要客戶,或被 Synopsys / Cadence / 自研 NoC 侵蝕。
  • 半導體設計週期下行,新授權 win 枯竭。
  • 小型股流動性 / 風險偏好逆轉,估值多殺多。
觸發任一項就重新檢視論點,不要凹單。
