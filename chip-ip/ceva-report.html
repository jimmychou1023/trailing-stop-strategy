研究結論

小型 IP · 成長改善中 · 回檔後報酬風險轉佳 · 試探

小型純 IP 授權商:DSP、無線連接(藍牙/Wi-Fi/UWB/5G)、Edge AI/NPU IP,靠授權 + 權利金賺錢。Q2 營收 +13%、FY26 指引上修到 13–15%、Non-GAAP 營益率由 3% 升到 11%。仍 GAAP 小虧;隨半導體殺盤,股價回落到 8/20 盤中 $28.82(開盤 $29.66)、市值 ~$8 億。機率加權合理價約 $34(預期差 +18%),報酬風險比升到約 2.37:1。體質改善、回檔後安全邊際轉佳,但仍屬高波動小型股——小·試探,盯獲利轉正與權利金放量。

在半導體 IP 中的定位:與 AIP 同等量級(小型純 IP),是最直接的同儕對照——AIP 做晶片內互連(NoC),CEVA 做DSP / 連接 / Edge AI。兩者都靠授權+權利金、都在「小型、成長、獲利爬坡」的階段。相對 ARM 的巨型龍頭,CEVA 是利基型小玩家。

1一頁研究表 · 12 問
Business1 · 公司靠什麼賺錢?
賣什麼、誰付錢、客戶為什麼換不掉它。
CEVA 是小型純 IP 授權商,三塊 IP:①DSP(訊號處理)、②無線連接(藍牙、Wi-Fi、UWB、5G)、③Edge AI / NPU(裝置端 AI 推論)。商業模式:授權金 + 出貨權利金。
付錢的是晶片設計商與品牌廠(手機、IoT、車用、消費電子)。換不掉的原因:IP 被設計進晶片後切換成本高、且每顆出貨付權利金;連接 IP 有標準與認證門檻。
TAM2 · 市場還能成長多久?
TAM 是判斷成長空間,不是簡報用的。
受惠邊緣 AI(裝置端 AI)、車用電子、無線連接普及——每個 IoT / 消費 / 車用晶片都可能用到連接或 DSP/NPU IP,是「量大、單價低、長尾權利金」的模式。
管理層看到手機、車用 AI、連接產品的中長期機會擴大。TAM 廣但競爭與單價壓力也在,關鍵是能否拿到夠多 design win 累積權利金。
Moat3 · 為什麼對手搶不走?
好到別人無法取代,才叫護城河。
護城河:連接 / DSP IP 的標準相容與認證、既有 design win 的權利金黏著、專利組合。
誠實面:護城河比 ARM 窄很多——客戶可能自研、或選 Synopsys/Cadence 等更大 IP 商;連接 IP 競爭激烈、單價受壓。CEVA 靠專精利基 + 授權彈性存活,但議價力有限。
Revenue4 · 成長來自哪裡?
價格還是數量?一次性還是 recurring?
Q2 2026 營收 $29M(+13%),授權與權利金雙成長。FY26 成長指引上修到 13–15%、H2 更強(手機回溫、車用 AI ramp、連接產品)。
屬性:授權(較一次性)+ 權利金(recurring、隨客戶晶片出貨)。規模小,單一大 design win 就能明顯影響——好處是彈性,壞處是波動大。
Margin5 · 利潤率是否改善?
Gross → Operating → FCF 一路看營業槓桿。
IP 模式毛利率高。重點是營業層面:Non-GAAP 營業利益率由 3% 升到 11%、FY26 non-GAAP 營益 +70%、淨利 +50%——營業槓桿開始發揮。
但 GAAP 仍小虧(近 12 月 -$11.8M),主要股權薪酬與投入。看點:營收成長能否讓 GAAP 也轉正、營益率續升。
FCF6 · 現金有沒有真的進來?
EPS 是會計結果,現金流較難長期演戲。
授權/權利金現金品質尚可(常有預收),公司手上有現金、無重大負債。GAAP 雖小虧,但 non-GAAP 獲利改善中。
留意小型股的 SBC 稀釋與現金消耗節奏。整體財務體質對小型 IP 股算健康,不需靠大額增資。
Balance Sheet7 · 能撐過景氣下行嗎?
小型股尤其要看資產負債表。
淨現金、無重大有息負債,加上營益改善,短期營運無虞。但規模極小(市值 ~$9 億),抗景氣循環與客戶集中風險的能力有限。撐得過一般下行,但屬高 beta 微型成長股。
Competition8 · 最大競爭者是誰?
用對手財報交叉驗證你這家的說法。
對手:Synopsys / Cadence(大型 IP)、Arm(部分 NPU/連接重疊)、以及客戶自研。連接 IP 領域也有多家專業廠。
CEVA 靠專精 DSP/連接 + 授權彈性 + 中立差異化,但議價力與規模都遠不如大廠。交叉看手機 / IoT / 車用晶片出貨與連接標準採用。
Catalyst9 · 未來 12–24 個月的催化劑?
把催化劑與時點寫下來。
  • GAAP 轉正 / 營益率續升——最關鍵的再定價事件。
  • Edge AI / NPU IP design win 放量。
  • 車用 AI、連接(UWB / Wi-Fi)產品 ramp。
  • 手機權利金回溫。
  • 約 11 月 Q3 2026 財報。
Expectations10 · 股價已經反映什麼?
Expectations Gap 預期差才是重點。
市值 ~$815M ÷ 營收 ~$112M ≈ 約 7 倍 P/S,對成長 13–15% 的小型 IP 便宜。市場已反映營益改善與 Edge AI 題材,近日隨半導體殺盤回落。
預期差:轉正(+18%)——成長與獲利改善是真的、回檔後估值便宜,但規模小、競爭激烈、單價受壓,宜以試探部位參與。
Valuation11 · Bear / Base / Bull 各值多少?
三情境比單一目標價有意義,詳見下方第 2 區。
CEVA 屬小型、非 GAAP 已改善但 GAAP 小虧的成長股,用 P/S 與轉盈進度評估較合理。核心變數:權利金放量、Edge AI 採用、GAAP 轉正、小型股風險偏好。三情境見下一區(依 8/20 盤中 $28.82 校準),不確定性高。
Thesis Break12 · 什麼事代表我錯了?
進場前就寫好,跌 40% 後大腦會自動編故事。
先寫下「認錯訊號」:
  • 成長掉回個位數、營益率改善停滯。
  • Edge AI / 連接 design win 不如預期。
  • 被大型 IP 商或客戶自研侵蝕、單價續跌。
  • GAAP 遲遲無法轉正、現金消耗加速。
  • 小型股風險偏好逆轉、估值多殺多。
觸發任一項就重新檢視論點,不要凹單。
